# Proposal

## Why

Нужен автономный мини-трекер учебных задач на неделю (ДЗ1, вариант B, см. `brief.md`): без CDN, внешних библиотек и API-ключей. Прогресс должен считаться по часам, а не по числу задач, а ввод — проверяться так, чтобы пустое значение не превращалось в ноль. Сначала фиксируется спецификация, затем отдельным запросом — реализация.

## What Changes

- Новый статический веб-интерфейс: список задач (id, title, hours, done) со стартовым набором «Чтение» 2 ч (готово), «Практика» 4 ч, «Повторение» 2 ч.
- Добавление, удаление и переключение статуса done реально меняют данные и интерфейс.
- Валидация формы: название после trim непустое; часы — число от 0,5 до 24 с шагом 0,5; пустое значение не равно нулю; ошибка рядом с полем, введённые значения сохраняются.
- Сводка: всего часов, выполнено часов, прогресс = round(100 × done_hours / total_hours), 0% при отсутствии задач (без NaN/Infinity).
- Фильтр списка (все / активные / выполненные) влияет только на видимые строки, но не на итоги и прогресс.
- Интерфейс читаем на ширине 390 px без горизонтального скролла; все поля и кнопки подписаны.
- Необязательное улучшение: сохранение в localStorage с понятным сообщением и работой в памяти, если хранилище недоступно.
- Автотесты (`tests/acceptance.test.mjs`) на расчёты, независимость метрик от фильтра, валидацию и пустое состояние; интерфейс проверяется вручную по T1–T5.

## Capabilities

### New Capabilities
- `tracker`: учёт учебных задач — список, добавление/удаление/переключение, валидация ввода, расчёт часов и прогресса, фильтрация, пустое состояние, адаптивность и необязательное сохранение.

### Modified Capabilities

(нет — в проекте ещё нет спецификаций)

## Impact

- Новые файлы в корне `with-spec/`: `index.html`, `styles.css`, `app.mjs`, `domain.mjs`, `tests/acceptance.test.mjs`.
- Зависимости: только встроенный `node:test` для тестов; в браузере — без библиотек.
- Вне рамок: бэкенд, аккаунты, редактирование задачи, сортировка, обязательная кнопка сброса, обязательное сохранение между перезапусками.
- Ограничение: при открытии через `file://` доступность localStorage зависит от браузера; это описывается в документации, а не гарантируется.
