# Мини-трекер учебных задач (with-spec)

Автономное приложение без CDN, библиотек и ключей: `index.html`, `styles.css`, `app.mjs`, `domain.mjs`, тесты в `tests/acceptance.test.mjs`. Спецификация — `openspec/changes/build-tracker/`.

## Запуск

Тесты и проверка синтаксиса (в этой папке):

```
node --test tests/acceptance.test.mjs
node --check app.mjs
node --check domain.mjs
```

Приложение (в PowerShell, если `npx` блокируется политикой выполнения, используйте `npx.cmd`):

```
npx.cmd --yes http-server@14.1.1 . -p 8081 -c-1
```

Откройте http://127.0.0.1:8081.

## Ограничения

- Страница использует ES-модули. При открытии двойным кликом (`file://`) часть браузеров блокирует загрузку модулей, поэтому запускайте через сервер.
- Задачи сохраняются в `localStorage`. При `file://` его доступность зависит от браузера. Если хранилище недоступно, показывается сообщение, а приложение продолжает работать в памяти.
- Автотесты покрывают только `domain.mjs` (расчёты, фильтр, валидацию, пустое состояние). Форма, кнопки, тексты ошибок и узкий экран проверяются вручную по T1–T5.
